🎮 Hangman Game — Python Project
Hey! This is a simple text-based Hangman game I built using Python as part of my internship at CodeAlpha. It runs completely in the terminal — no graphics, no fancy stuff, just pure Python logic.

📌 What is this project?
Hangman is a classic word-guessing game. The computer secretly picks a word, and you have to guess it one letter at a time. Every wrong guess costs you a life. You only get 6 lives — so choose wisely!

🕹️ How to Play

Run the program
You'll see blank spaces like: _ _ _ _ _
Type one letter and press Enter
If your letter is in the word — it gets revealed!
If not — you lose a life
Keep guessing until you complete the word or run out of lives


# How to Run It
Make sure Python is installed on your computer, then:
bashpython hangman.py
That's it. No extra libraries needed!
